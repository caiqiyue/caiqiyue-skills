# 表层 AI 痕迹清单

判断"这张表像不像 AI 生成 / 数据像不像编的"。判据**语言无关**。

分两档：**类① 风格痕迹**（真实数据也可能踩，主要关"AI 帮排版/润色"的痕迹），
**类② 造假取证**（只在怀疑数据本身是编的时候启用）。

> **总免责**：本 skill **不替代统计学造假鉴定工具，也不下"数据造假"的最终结论**。
> 类② 每一条单独都不构成结论，命中后的措辞只能是"**建议用 XX 工具 / 原始数据复核**"。
> 取证判据 Benford / GRIM / statcheck 等都有**严格适用前提**，不满足前提就**不要用**——
> 用错会把真实数据误判成造假，这是本层最大的误伤风险。**类② 比类① 更易误伤，门槛要更高、措辞要更克制。**

---

## 类① 风格性 AI 痕迹（真实数据更相关）
- **全表等位小数**：整张表精度一刀切（所有数都恰好 4 位小数），真实测量值精度常有自然参差。
- **每行都加粗"最优"**：机械地把每行最大值加粗，连差异无意义的也加。
- **满表箭头**：到处 ↑↓、↗↘，装饰性强。
- **可疑的整齐圆整数**：一列数据过于规整、扎堆 0/5 结尾。
- **列与列严格等差 / 等比**：相邻列恒定差或恒定比（像派生出来的，不是各自测的）。
- **表注是生成式空话**："This table presents the comparison of different methods."
- 改法：精度按指标实际有效位、加粗只标真有显著差异的、去掉无意义箭头、表注写清这张表
  支撑了什么结论。注意：这些多是"排版/润色"痕迹，**不等于数据有问题**，别上纲到造假。

## 类② 造假取证（怀疑数据编造时才启用，肉眼可用版 + 适用前提）

- **末位数字异常**（适用面最广、最稳）：把一列数的**末位数字**摊开看，若分布明显不均、
  过度偏好 0 或 5，可能有人为"凑整"痕迹。真实测量的末位通常接近均匀。
- **列间恒定差 / 比、过度规整**：相邻列/行严格等差或等比、整列圆整数——疑似派生或复制。
- **GRIM / GRIMMER**：检查"报告的均值（GRIM）/ 标准差（GRIMMER）"与"样本量 + 报告精度"
  是否**数学上可能**（例如 n=20 的整数评分，均值不可能恰好 .37 结尾）。
  ⚠️ **仅对整数 / 离散数据**（Likert 量表、计数、整数评分总分）的均值/方差有效；
  对连续测量量（时间、长度、连续分数）**不适用，套用会大量误报**。先确认数据是离散的。
- **statcheck**（p 值反推）：用文中报告的检验统计量 `t / F / χ²` 及自由度反推 p 值，
  看与作者写的 p 值 / 显著性结论是否矛盾（尤其有没有"该不显著却写了显著"的反转）。
  ⚠️ **仅当完整报告了统计量时可用**。论文表格**通常只列 p 值、不列统计量，多数情况无法套用**，
  缺统计量就别强行用，标"无法判定"。
- **Benford 首位律**：⚠️ **慎用、默认不用**。Benford 只对"**跨多个数量级、有量纲的自然计数**"
  成立。CS/ML 论文表里占主导的是**有界量**（准确率 / F1 / 百分比 0–100 / 相关系数 / p 值 /
  归一化指标），这些**本就不服从 Benford**，套用**必然误判**。仅当表中是真正跨量级的原始
  计数（样本量、词频、金额）时才可作参考。
- **SPRITE / TIVA**：更深的分布级取证（均值±标准差能否还原出合理原始分布、多组方差是否过于
  一致）。本 skill **不精算**，只作为"**建议送 PaperGuard 等工具复核**"的指向。

---

## 表层判断小结
- 多数真实论文的表，问题集中在**类① 风格**（排版/润色痕迹），措辞停在"建议优化呈现"。
- 类② 只在**有合理理由怀疑数据**时启用，且**先过适用前提**：是不是离散数据（GRIM）、
  有没有统计量（statcheck）、是不是跨量级计数（Benford）。前提不满足，写"无法判定"，
  不要把真实数据冤成造假。
- 用户实测中明显的 AI 表尚少见；类① 按特征预判，类② 作为客观备查。
