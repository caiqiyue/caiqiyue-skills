# Quickstart

Use this skill when a repository lacks a stable AI operating framework.

## Output Goals

- the repository profile is identified
- the minimum `.ai` framework exists
- exactly one feature is active
- the repository is ready for planner -> implementer -> reviewer -> verifier

## Minimum Initialization Checklist

1. Inspect stack markers.
2. Select the nearest profile.
3. Copy the project framework assets into repository root.
4. Replace placeholders in `active-task.md` and `feature-list.json`.
5. Confirm the two hard rules are visible in both entry files and policy files.
