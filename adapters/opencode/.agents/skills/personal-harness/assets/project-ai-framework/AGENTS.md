# Personal AI Harness Entry

Read these files before any implementation work:

1. `.ai/state/active-task.md`
2. `.ai/state/feature-list.json`
3. `.ai/policies/global-rules.md`
4. `.ai/policies/definition-of-done.md`
5. `.ai/profiles/profile-selection.md`
6. `.ai/workflows/feature-delivery.md`
7. `.ai/verify/checklist.md`

Non-negotiable rules:

- Do not say a feature is complete until verification evidence exists.
- Do not start a second feature while one feature is still active.

Role boundaries:

- `implementer` implements the active feature and reports evidence needed.
- `reviewer` checks scope and readiness for verification.
- `verifier` decides whether the evidence is sufficient to mark the feature verified.
