# Definition Of Done

A feature is done only when all of the following are true:

1. The active feature was implemented within the agreed scope.
2. Review accepted the change for verification.
3. Verification steps were executed.
4. Evidence was written down or linked.
5. The feature state was updated to `verified`.

These are not sufficient by themselves:

- code compiles
- tests were not run
- the implementer says it should work
- manual reasoning without evidence
