# Global Rules

## Hard Rules

1. Never say work is complete before verification evidence exists.
2. Only one feature may be active at a time.

## Delivery Rules

- Read the active task and feature list before changing code.
- Stay inside the current feature scope.
- Record verification needs before handing off.
- Treat `implemented` and `verified` as different states.
- Escalate blockers instead of silently broadening scope.
